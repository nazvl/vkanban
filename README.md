# Система управления задачами (Kanban-доска)

## Цель проекта

Сделать систему управления задачами: доски, колонки, карточки, участники, комментарии, дедлайны.  
Опционально — drag & drop и realtime.

---

## Описание проекта

Необходимо разработать Kanban-доску для командной работы с задачами. Система должна позволять пользователям создавать доски, управлять колонками и карточками, назначать исполнителей, оставлять комментарии и отслеживать дедлайны.

---

## MVP (обязательный минимум)

### Пользователи и доступ

- Регистрация / логин.
- Доска имеет владельца и участников.

### Доски

- Создание.
- Удаление.
- Редактирование.
- Список досок пользователя.

### Колонки

- Создание.
- Переименование.

### Карточки

- Создание и редактирование `title` и `description`.
- Перемещение между колонками.
- Порядок в колонке.
- Назначение исполнителя.
- Дедлайн.

### Комментарии

- Комментарии к карточке.

---

## Расширения

- Теги / лейблы и фильтр по ним.
- Чек-лист внутри карточки.
- Вложения.
- История изменений: audit log.
- Realtime-обновления через WebSocket: перемещения и комментарии.
- Поиск по карточкам.
- Шаблоны досок.

---

## Алгоритм выполнения проекта

1. Изучить требования к кейсу и изучить Trello.
2. Спроектировать сущности в реляционной базе данных.
3. Выбрать фреймворк для frontend-части.
4. Разработка frontend-части, реализация backend-части для работы с базой данных.
5. Тестирование, отладка.

---

## Какие навыки и компетенции нужны для выполнения

- Frontend-разработка.
- Реляционные БД.
- Backend-разработка.

---

## Какой результат хотим получить

Разработанная система управления задачами с UI: доски, колонки, карточки, участники, комментарии, дедлайны.  
Опционально — drag & drop и realtime.
